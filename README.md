## 🏛️ Architecture & Highlights

- **VS Code Chrome Simulation:** Pixel-precise title bar, functional top menu bar with cascading dropdowns, activity bar with view controls, collapsible file explorer, multi-tab buffer management, breadcrumbs, and live status bar telemetry.
- **Integrated Interactive Terminal (`hashir@portfolio:~$`):** Fully operational command-line interface supporting system queries (`whoami`, `projects`, `skills`, `experience`, `education`, `certs`, `contact`, `cv`, `git status`, `theme [name]`, `clear`).
- **Portfolio AI Assistant (Copilot):** Integrated conversational assistant equipped with contextual knowledge regarding Hashir's system architectures, diagnostic ML benchmarks, engineering internships, and leadership track record.
- **Fuzzy Command Palette (`Ctrl+P`):** Keyboard-driven command palette enabling instant jumping between project files, executing runtime commands, and toggling themes.
- **Multi-Theme Engine:** Dynamic switching across four curated developer themes: *Hashir Dark*, *Tokyo Night*, *Catppuccin*, and *Nord*.
- **Integrated Curriculum Vitae Viewer:** High-performance PDF reader embedding `Hashir_cv.pdf` with responsive mobile fallbacks and one-click direct download triggers.
- **Production Systems Showcase:** In-depth technical specifications of enterprise applications, clinical diagnostic systems, and explainable ML pipelines.

## 💻 Local Execution

To inspect the portfolio locally, clone the repository and open `index.html` in any modern web browser, or launch a lightweight HTTP server:

```bash
# Python 3
python3 -m http.server 8080

# Or via Node.js
npx serve .
```

Navigate to `http://localhost:8080` to access the interactive workspace.
